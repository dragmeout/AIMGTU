# Данные для RAG

В этой работе используется база из второй лабораторной: 70 документов по 16 темам. Текст документов не менялся.

- `documents/clean_documents.jsonl` — документы с текстом, блоками, страницами и метаданными.
- `documents/clean/` — копии для чтения в Markdown.
- `sources.csv` — реестр официальных источников.
- `documents/manifest.json` — журнал исходной загрузки из работы №2. Пути `raw/` в нём относятся к архиву второй работы; её исходные HTML и PDF здесь не дублируются.
- `indices/e5_128/`, `e5_256/`, `e5_384/` — фрагменты, FAISS-индекс и контрольные суммы каждого варианта.
- `evaluation/dev.jsonl` — 20 вопросов для выбора параметров.
- `evaluation/test.jsonl` — 16 других вопросов для итогового сравнения.
- `evaluation/protocol.json` — порядок экспериментов и правило выбора, заданные до генерации ответов.
- `evaluation/lab2_questions.jsonl` — исходные 67 сценариев второй лабораторной; в эксперимент вошли 36 из них.

В работе №2 фрагменты измерялись словами. Здесь разбиение выполнено заново в токенах E5: 128, 256 и 384, с перекрытием примерно 32 токена. У каждого фрагмента проверяется фактическая длина; текст не обрезается при вычислении эмбеддингов. Заголовок документа добавляется отдельно и ограничен 32 токенами.

`start_char` и `end_char` указывают на точный отрывок исходного очищенного текста. `pages` содержит физические страницы PDF для блоков, затронутых фрагментом. Они могут отличаться от напечатанных номеров листов. Для HTML список страниц пуст.

Снимки получены 04.10.2026 и 01.11.2026. Наличие текста в базе не подтверждает, что правило действует сегодня. Применимость версий и расхождения источников описаны во второй лабораторной. Персональные оценки, долги за обучение и текущее наличие мест не собирались.

Для 35 новых документов добавлен отдельный набор `evaluation/new_documents.jsonl`; он используется для проверки охвата новых источников, а не для подбора параметров.
