# ИИ-ассистент студента МГТУ — лабораторная работа № 1

Комплект проектных артефактов для прототипа интеллектуального ассистента студента ФГБОУ ВО «МГТУ им. Г. И. Носова».

## Состав

- `docs/project_description.md` — описание проекта, аудитория, границы и обоснование ИИ;
- `docs/requirements.md` — функциональные и нефункциональные требования;
- `docs/use_cases.md` — семь основных пользовательских сценариев;
- `docs/risks.md` — реестр рисков и меры снижения;
- `docs/architecture_v1.png` — архитектура первой версии;
- `ai_usage/ai_log.md` — фиксация использования генеративного ИИ при подготовке работы.

## Статус

Это проектная документация версии 1.0. Числовые пороги качества и перечень источников должны быть уточнены после сборки базы знаний и первых экспериментов. Персональные данные студентов в версию 1 не входят.
