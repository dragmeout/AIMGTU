# Тезисы защиты — исправленная лабораторная №1

1. Это локальный RAG-ассистент по официальным документам МГТУ. Источник приоритетнее генерации; при недостатке данных — отказ или уточнение.
2. Embeddings: `intfloat/multilingual-e5-small`, 384-мерные нормализованные векторы. Одинаковая модель для документов и вопросов; префиксы `passage: ` и `query: `.
3. Поиск: FAISS IndexFlatIP, до 5 кандидатов, до 3 допустимых chunks в контекст. Порог калибруется, а не выбирается наугад.
4. Генерация: `Qwen2.5-1.5B-Instruct`, GGUF Q4_K_M, llama.cpp на CPU. Один вызов модели после проверки доказательств, без инструментов и агента.
5. UC-06 выполняется retrieval по заранее индексированным описаниям подразделений. Модель не классифицирует тему отдельно и не посещает сайт; URL формирует код из метаданных найденного документа.
6. Целевой компьютер для другой команды: 8 ГБ RAM, CPU x86-64/AVX2 с четырьмя ядрами, без обязательной видеокарты. Контекст 2048, ответ до 256 токенов, один запрос одновременно. Пиковая память ещё подлежит измерению на готовом прототипе.
7. Модель подготовки текущей редакции — OpenAI `gpt-6.1-sol` (версия 6.1) через Codex; она не входит в локальный ассистент. Для старой записи неизвестная версия не выдумана.
8. Программные правила проверяют явные запреты, даты, метаданные и ID источников. Их пределы указаны; correctness, faithfulness и отказы проверяются benchmark из ≥100 сценариев.
