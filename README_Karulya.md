# Каруля И. С.. Лабораторные №2 и №3

Корпус обновлён до 70 документов. Это распределение материалов и ответственности. Каждый участник проверяет свой блок и фиксирует фактический вклад.

## Лабораторная №2: Сбор, очистка и структура документов

Каруля И. С. — сбор и очистка

«База расширена с 6 до 70 документов по 16 темам. Из них 67 содержат сведения и правила, ещё 3 помогают найти нужный сервис.

Из HTML убраны меню, формы, комментарии и рекламные блоки. Из PDF извлечён основной текст без повторяющихся шапок. Списки, строки таблиц и страницы сохранены. Разные ссылки на одну страницу не считаются отдельными документами. Сканы и инструкции с неполным текстом исключены до проверки».



## Лабораторная №3: Эмбеддинги, разбиение по токенам и FAISS

**Каруля И. С.** Документы разделены в токенах E5, чтобы соблюдать лимит модели. Для размеров 128, 256 и 384 построены индексы на 1470, 650 и 428 фрагментов. E5 выдаёт 384-мерные нормированные векторы; FAISS ищет ближайшие по скалярному произведению. Границы и покрытие текста проверяются тестами.

Результаты после расширения базы пересчитаны. Ориентир памяти процессов: 8 ГиБ предпочтительно, 16 ГиБ допустимо. Полный отчёт о новых документах и ограничениях — в docs/corpus_expansion.md соответствующей лабораторной после объединения.

## Как собрать проект

Распакуйте все четыре архива в одну папку. В каждом сохранены корни AIMGTU-lab2 и/или AIMGTU-lab3. Файлы проектов распределены без повторов: каждый файл находится ровно у одного участника.

После объединения откройте README.md нужной лабораторной. Во второй лабораторной команда python scripts/prepare_data.py all пересобирает данные без сети. В третьей сначала установите зависимости и загрузите модели командой python scripts/download_assets.py, затем используйте python run.py ask "Ваш вопрос". Модели не входят в архивы; загрузчик проверяет их SHA-256. Для запуска всего приложения нужны части всех четырёх участников.

Общий README, основные отчёты и команды запуска находятся у Домашева; документы — у Карули; источники и загрузчик моделей — у Чуракова; вопросы, результаты и эксперименты — у Замиралова.
