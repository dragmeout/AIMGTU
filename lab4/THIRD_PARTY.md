# Модели, данные и библиотеки

Веса и исполняемые файлы загружаются из официальных репозиториев. В архив исходного кода они не включены. Точные версии, адреса, размеры и SHA-256 перечислены в `config/assets.json`.

| Компонент | Лицензия | Источник |
|---|---|---|
| intfloat/multilingual-e5-small | MIT | https://huggingface.co/intfloat/multilingual-e5-small |
| Qwen2.5-1.5B-Instruct-GGUF | Apache-2.0 | https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF |
| llama.cpp | MIT | https://github.com/ggml-org/llama.cpp/tree/b12032 |
| ONNX Runtime | MIT | https://github.com/microsoft/onnxruntime |
| FAISS | MIT | https://github.com/facebookresearch/faiss |
| Hugging Face Tokenizers | Apache-2.0 | https://github.com/huggingface/tokenizers |

Условия конкретной версии компонента нужно смотреть в его репозитории. Python-зависимости зафиксированы в `requirements.txt`.

Материалы университета взяты из подготовленной базы лабораторной №2. Их адреса и решения о включении сохранены в `data/sources.csv`. Свободная лицензия сайта не была найдена; право на открытое переиздание полных текстов отдельно не подтверждалось. Корпус предназначен для учебного проекта.
