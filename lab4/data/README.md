# Данные четвёртой лабораторной

`documents/clean_documents.jsonl` и `documents/clean/` содержат 70 документов только МГТУ им. Г. И. Носова. Текст не менялся после лабораторной №3. Оригиналы HTML и PDF находятся в архиве второй лабораторной; пути raw в манифесте относятся к ней.

`tools/departments.json` — справочник 25 подразделений. Значение каждого поля связано с точным отрывком и SHA-256 исходного текста. Правила имён и синонимов находятся в `config/directory_rules.json`. Обновление: получить и проверить новую версию корпуса, изменить правила при необходимости, выполнить `python scripts/build_directory.py`, тесты и эксперименты. Контакты проверяются раз в неделю, положения — раз в месяц. Ошибка загрузки не обновляет дату снимка.

`indices/e5_384/` используется в A и B. Векторы для 128 и 256 также сохранены из предыдущей работы, но в новом сравнении не применяются. Данные индексов проверяются по контрольным суммам. Модель E5 и её код не менялись.

`evaluation/ab_cases.jsonl` — 28 вопросов; `ab_protocol.json` — протокол; `security_cases.jsonl` — 16 атак и четыре контроля. Вопросы составлены с помощью ИИ. Доступа к актуальному расписанию и личным данным студентов нет. Синтетический файл в tests/fixtures используется только в опыте безопасности и не индексируется.
