# Ассистент МГТУ для Windows x64

Оба архива используют Cherry Studio, Ollama, Qwen3.5-9B и базу из 155 материалов МГТУ. Выберите размер контекста для своего компьютера.

| Архив | Контекст | Когда выбрать |
|---|---:|---|
| [MGTU-Assistant-Windows-x64-32768.zip](./MGTU-Assistant-Windows-x64-32768.zip) | 32 768 | Для длинных документов и переписки |
| [MGTU-Assistant-Windows-x64-8192.zip](./MGTU-Assistant-Windows-x64-8192.zip) | 8 192 | Для первой проверки на ноутбуке с 16 ГБ ОЗУ |

1. Скачайте один ZIP и распакуйте его целиком.
2. Запустите `setup.cmd` с интернетом. Скрипт скачает программы и модели. Для первой установки потребуется примерно 9,14 ГБ трафика.
3. Запустите `start.cmd` и выполните настройку Cherry по `docs/START_RU.md` внутри архива. Инструкция включает значения контекста и входного лимита для выбранной версии.
4. Для следующих запусков используйте `start.cmd`. Для остановки используйте `stop.cmd`, для диагностики — `doctor.cmd`.

При переходе между версиями сначала остановите запущенный комплект через его `stop.cmd`. Вариант на 8 192 токена экономит память за счёт более короткой истории. Скорость на ноутбуке Intel зависит от процессора и графического драйвера. Эта конфигурация на ноутбуке с 16 ГБ не проверялась.

В архивы входят код, скрипты, документы, индекс и файлы импорта Cherry. Установочные файлы и веса моделей скачивает `setup.cmd`.
