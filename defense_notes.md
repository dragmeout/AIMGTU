# Короткий ответ на контрольный вопрос

ИИ нужен для понимания свободной формулировки вопроса, смыслового поиска и краткого синтеза нескольких официальных фрагментов. Обычные правила при этом остаются для точных и критичных проверок. Если эксперимент не покажет преимущества RAG над обычным поиском для некоторого класса вопросов, там следует оставить обычный поиск — это тоже обоснованный результат проекта.
