# Получение оригиналов документов об образовании

Источник: https://www.magtu.ru/alumni/poluchenie-originalov-dokumentov-ob-obrazovanii.html

## Основной текст

ВАЖНО! В случае невозможности личного присутствия для получения документов об образовании возможно получение по доверенности. Форма размещена на сайте МГТУ им. Г.И. Носова по ссылке (https://www.magtu.ru/component/jdownloads/send/263-vysshee-obrazovanie/8665-doverennost.html). В данном случае уполномоченное лицо предоставляет документ удостоверяющий личность, ксерокопии паспортов доверителя и уполномоченного, заполненный бланк доверенности.

При возникновении вопросов Вы можете связаться с Отделом по работе с выпускниками (https://www.magtu.ru/sveden/struct/strukturnye-podrazdeleniya/upravleniya/uchebno-metodicheskoe-upravlenie/%D0%BE%D1%82%D0%B4%D0%B5%D0%BB-%D0%BF%D0%BE-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B5-%D1%81-%D0%B2%D1%8B%D0%BF%D1%83%D1%81%D0%BA%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC%D0%B8.html) МГТУ им. Г.И. Носова с 8-00 до 12-00
