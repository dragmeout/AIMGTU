# Стипендии и меры поддержки обучающихся

Источник: https://www.magtu.ru/sveden/grants.html

## Основной текст

Стипендией признается денежная выплата, назначаемая обучающимся в целях стимулирования и (или) поддержки освоения ими соответствующих образовательных программ.

В ФГБОУ ВО «МГТУ им. Г.И. Носова» размер государственной академической стипендии составляет:

- для обучающихся по программам ВО - 3078 руб.,
- студентов по программам СПО - 1310 руб.,

Размер государственной социальной стипендии составляет:

- для обучающихся по программам ВО - 5600 руб.
- для обучающихся по программам ВО 1 и 2 курса, обучающихся на «хорошо» и «отлично» - 12815 руб.
- для студентов по программам СПО - 1968 руб.

Размер государственной стипендии для аспирантов:

- обучающихся не по приоритетным техническим и естественным направлениям подготовки научно-педагогических кадров, составляет 12 066 руб.,
- для аспирантов, обучающихся по приоритетным направлениям подготовки научно-педагогических кадров – 18 195 руб.

Для обучающихся по программам среднего общего образования выплата стипендий не предусмотрена

## Меры социальной поддержки обучающихся, по программам ВО и СПО, члены семей которых призваны на военную службу по мобилизации

К мерам социальной поддержки относятся:

1. Единовременные выплаты материальной помощи в соответствии с локальными актами университета.
2. Освобождение от оплаты за проживание в общежитии.
3. Предоставление скидки за оказание платных образовательных услуг в размере 100% на 6 месяцев или до конца обучения в соответствии с локальными актами университета. ## Меры поддержки обучающихся, проживающих в общежитии

Для лиц, получающих государственную социальную стипендию сумма оплаты за проживание составляет 1000 руб./чел. в месяц в счет возмещения затрат за потребленные коммунальные услуги. Не взимается плата за проживание в общежитиях со следующих категорий обучающихся:

- дети-сироты и дети, оставшиеся без попечения родителей;
- лица, из числа детей-сирот и детей, оставшихся без попечения родителей;
- дети-инвалиды;
- инвалиды I, II и III групп;
- инвалиды с детства;
- лица, подвергшиеся воздействию радиации вследствие катастрофы на Чернобыльской АЭС и иных радиационных катастроф, вследствие ядерных испытаний на Семипалатинском полигоне;
- инвалиды вследствие военной травмы или заболевания, полученного в период прохождения военной службы, ветеранами боевых действий;
- лица, являющиеся участниками боевых действий;
- лица, имеющие единственного родителя – инвалида I-ой группы
