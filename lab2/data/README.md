# База знаний ИИ-ассистента студента МГТУ

Снимок от **04.10.2026**, лабораторная работа №2. Это фактически собранный пилотный корпус официальных материалов МГТУ им. Г.И. Носова.

## Состав

```text
data/
├── README.md
├── sources.csv                       # 14 источников и кандидатов, решения и ограничения
├── preparation_config.json           # белый список доменов и параметры разбиения
├── documents/
│   ├── manifest.json                 # результаты загрузки, даты и SHA-256
│   ├── raw/                          # 7 оригинальных снимков: 5 HTML и 2 PDF
│   ├── clean/                        # 6 очищенных документов: JSON + Markdown
│   └── clean_documents.jsonl         # канонический очищенный корпус
├── chunks/
│   ├── fixed.jsonl                   # 35 окон по 180 слов, overlap 30
│   ├── semantic.jsonl                # 34 смысловых фрагмента, максимум 260 слов
│   ├── final.jsonl                   # выбранный вариант; идентичен semantic.jsonl
│   ├── schema.json                   # схема метаданных
│   └── example.json                  # реальный пример записи
├── evaluation/
│   └── questions.jsonl               # 20 вопросов с evidence + 4 сценария отказа
└── reports/
    ├── refresh_report.json
    ├── cleaning_report.json
    ├── build_manifest.json
    ├── chunking_comparison.json
    ├── chunking_comparison.md
    ├── retrieval_details.jsonl
    ├── validation_report.json
    └── verification.md
```

Форматы JSON/JSONL/Markdown — UTF-8; `sources.csv` — UTF-8 с BOM, разделитель запятая. Одна строка JSONL — одна самостоятельная запись; переводы строк внутри `text` экранированы JSON.

## Воспроизведение

Из корня проекта, Python **3.12**:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-data.txt
.\.venv\Scripts\python.exe scripts/prepare_data.py all
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`all` работает **без сети**: проверяет сохранённые оригиналы, очищает документы, создаёт оба варианта chunks, повторяет эксперимент и валидирует результат. Интернет нужен только при установке зависимостей и отдельном обновлении источников. На Linux используются `.venv/bin/python` и те же аргументы.

Команды этапов:

```powershell
python scripts/prepare_data.py build
python scripts/prepare_data.py compare
python scripts/prepare_data.py validate
python scripts/search_kb.py "структура отчета по практике" --top-k 3
```

Поиск демонстрационный, BM25, без генерации ответа. Для будущего RAG импортируется **только `chunks/final.jsonl`**. В индекс передаётся `retrieval_text`, для цитирования — `text`, `source`, `pages`, `document_title`. `fixed.jsonl` остаётся контролем эксперимента. Файлы работы №1, тестовые вопросы и отчёты в индекс не входят.

## Ограничения актуальности

- `date` — дата документа, а не скачивания. Для недатированных HTML — `null`.
- Регламент утверждён 13.03.2024, протокол №6: реквизиты прочитаны с изображения титула. Отсутствие более новой редакции не подтверждено.
- Один PDF из 14 сканированных страниц сохранён, но **не индексируется** без OCR и проверки.
- Семь источников возвращали редирект вне официальных доменов. Их содержимое не заменялось поисковыми пересказами.
- База покрывает практику, карьерные консультации, навигацию по расписанию и общие контакты. Актуальные размеры стипендий, фактическое расписание групп, общие правила пересдач и порядок выдачи справок пока не покрыты.
- Фрагменты имеют `allowed_use` и `validity_status`. Нельзя использовать их как подтверждение действующих сумм, сроков или индивидуальных решений. Для справочного ответа по исторической редакции указывается дата и статус источника.

## Обновление

`python scripts/prepare_data.py fetch` выполняет новую загрузку и меняет `manifest.json`; сохранённая текущая сборка остаётся воспроизводимой до запуска `build`. Поэтому сначала скопируйте проект как новую версию для обновления.

Новый сырой хеш, не совпадающий с `reviewed_raw_sha256` в реестре, **не допускается** в индекс автоматически. После проверки содержания, структуры и дат ответственный участник обновляет строку реестра и её reviewed-хеш, затем запускает `all`. Хеш скопировать механически без проверки нельзя. При ошибке доступа старая копия сохраняется в архиве, но не становится новой актуальной записью. Полные правила: `../docs/data_preparation.md`.

## Использование материалов

Разрешённый в проекте состав ограничен публичными официальными страницами, фактическими сведениями и опубликованным локальным регламентом для локального учебного исследования с сохранением атрибуции. Закрытые кабинеты, персональные данные студентов, чаты, отзывы и сторонние материалы исключены. Открытая лицензия и отдельное разрешение правообладателя на публичное переиздание полного корпуса не установлены; сборка не заявляет такого разрешения. Основание отбора отражено по каждой строке `sources.csv`.
