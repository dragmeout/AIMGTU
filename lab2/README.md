## Запуск

Python 3.12; платные API, GPU и языковая модель для этого этапа не нужны.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-data.txt
.\.venv\Scripts\python.exe scripts/prepare_data.py all
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Команда `all` работает без сети на приложенных оригиналах и воспроизводит оба варианта разбиения, эксперимент и проверки. Интернет нужен для первоначальной установки зависимостей или отдельной команды обновления `fetch`.

## Результат

Выбрано смысловое разбиение: оно сохраняет все 97 блоков размером до 180 слов и даёт полное подтверждение в top-3 для 18 из 20 вопросов. Фиксированные окна дают 17 из 20 в top-3, но лучше по top-1. Оба результата отражены в отчёте.

База пилотная. Семь кандидатов не загружены из-за внешнего редиректа, один сканированный PDF не индексируется без OCR. Неизвестная актуальность отмечена в метаданных; текущие размеры стипендий и расписание конкретных групп не представлены.
